## 角色定义

| 角色 | 标识 | 权限范围 |
|------|------|----------|
| 系统管理员 | `system_admin` | 全部功能 |
| 院系管理员 | `dept_admin` | 本单位实验室、变更初审 |
| 实验室管理员 | `lab_admin` | 所辖实验室、实验员 |
| 教师 | `teacher` | 查看、提交变更/预约 |
| 学生 | `student` | 查看、预约申请 |
| 临时人员 | `guest` | 受限查看 |

## 变更审批流程

```
draft → pending_unit（所在单位审核）→ pending_center（管理中心审核）→ approved
                              ↘ rejected（任一节点可驳回）
```
