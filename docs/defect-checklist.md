## 4. 缺失前端页面（UI-002 明细）

以下能力在后端已有或部分有 API，但 **Web 端无对应页面**：

1. **空间管理独立页** — 楼栋/楼层/房间维护
2. **实验室编辑页** — 仅有详情只读，无 `/labs/:id/edit`
3. **仪器新建/编辑页** — 列表页无「新建仪器」入口
4. **预约日历视图** — 仪器/实验室 calendar API 未接入 UI
5. **预约规则配置页** — 仪器/实验室规则
6. **使用记录填报页** — 仪器/实验室 usage 填报与审核
7. **用户管理页** — `/users` 后台管理
8. **故障二维码展示页** — 扫码入口与 QR 展示

## 5. 已知缺陷（Bug 级）

| 编号 | 严重程度 | 描述 | 复现 | 建议修复 |
|------|----------|------|------|----------|
| BUG-001 | 中 | 楼层/房间创建 API 参数与文档/前端不一致 | `POST /floors` 缺 `floor_number` 返回 422 | 统一 schema 文档；LabForm 创建空间时补全字段 |

| BUG-003 | 低 | 批量复制同课程时 422 | `batch-copy` 目标课程=源课程 | 前端校验或后端允许同课程副本 |
| BUG-004 | 高 | labs/experiments/spaces 等 API **无鉴权** | 未登录可 CRUD | 生产前必须加 auth |
| BUG-005 | 低 | 仪器列表无「新建」按钮 | 打开 `/instruments` | 增加 InstrumentForm 路由 |
