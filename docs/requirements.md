# 实验室管理系统 — 需求规格说明书

> 版本：v1.0 | 来源：校方采购/建设需求

## 1. 系统定位

面向高校实验室的综合管理平台，覆盖实验室信息、设备仪器、预约审批、实验项目、故障上报、数据填报、统计分析、外部系统对接及经营性收费等全业务链条。

**架构要求：** B/S 架构，支持本地化/云端部署，分层设计（表示层 / 业务逻辑层 / 数据访问层），兼容 Windows/Linux，前端兼容 Chrome/Firefox/Edge。

## 3. 模块详细需求

### M01 实验室信息管理

#### 3.1.1 实验室基本信息管理

| 需求项 | 说明 |
|--------|------|
| 信息录入 | 实验室名称、编号、楼栋/楼层、具体位置、面积、功能分区、容纳人数、责任负责人、开放状态（开放/关闭/维护中） |
| 多维检索 | 按楼栋、楼层、功能类型、开放状态筛选 |
| 批量操作 | 支持 Excel 批量导入与导出 |

#### 3.1.2 实验室变更管理

| 需求项 | 说明 |
|--------|------|
| 变更申请 | 功能调整、负责人变更、设备增减、区域划分调整 |
| 多级审批 | 所在单位审核 → 实验室管理中心审核 |
| 进度追踪 | 实时查询、消息推送、全程留痕 |

#### 3.1.3 实验员管理

| 需求项 | 说明 |
|--------|------|
| 人员信息 | 工号、姓名、责任管理实验室（一人多室）、联系电话、办公室地点 |
| 关联绑定 | 实验员与实验室的绑定及调整 |

---

### M02 实验室设备管理

#### 3.2.1 设备基本信息管理
- 与学校资产管理系统对接，自动同步资产编号、名称、分类、价值
- 支持配套设备补充维护与手动录入

#### 3.2.2 仪器台账管理
- 字段：仪器名称、型号、生产厂家、出厂编号、资产编号、购置日期/价格、存放实验室及位置、责任人
- 技术状态：正常/维修中/停用/报废，变更记录时间与原因
- 批量导入导出（Excel）

#### 3.2.3 仪器预约规则配置
- 逐台或分组设置开放时段（精确到小时）
- 单次预约时长上下限、每日/每周次数限制、提前预约时间
- 校内/校外用户差异化规则（优先级、收费标准、审批差异）

#### 3.2.4 仪器在线预约
- 按名称、类型、实验室查询
- 日历/时间轴展示空闲/占用/已预约状态
- 在线提交预约（时段、用途、实验项目、申请人信息）

#### 3.2.5 仪器预约审批
- 仪器负责人审批 / 多级审批两种模式
- 审批进度查询，微信/钉钉/系统消息推送

#### 3.2.6 仪器使用记录
- 使用内容、实验参数、耗材用量、运行状态反馈
- 上传数据文件及现场照片
- 负责人审核确认，意见留痕

#### 3.2.7 设备统计分析
- 按实验室、设备类型、时间维度统计频次/时长/使用率
- 按设备价值区间分层统计
- 报表导出与可视化

---

### M03 实验室预约管理

#### 3.3.1 预约规则配置
- 逐间设置开放时段、可预约范围、单日限额
- 按使用类型（教学/科研/开放/竞赛/社会服务）差异化规则

#### 3.3.2 预约申请
- 查看可用时段，选择日期时段，填写用途/人数
- 单次预约与周期性批量预约

#### 3.3.3 预约审批与门禁联动
- 按使用类型配置审批流程，结果实时推送
- 审批通过后联动授权：二维码/人脸/密码/课表自动开门
- 对接学校门禁管理系统

#### 3.3.4 预约记录管理
- 集中查看，多条件筛选，导出

#### 3.3.5 预约核验与签到
- 一卡通刷卡、扫码、人脸识别入场核验
- 实际到场人数与预约人数比对

#### 3.3.6 使用记录填报与确认
- 使用完毕在线填报，上传附件
- 管理员审核确认，支持批量审核

#### 3.3.7 实验室使用统计
- 开放时长、使用人次、使用类型分布
- 周/月/学期/学年/自然年多维度使用率
- 图表可视化与导出

#### 3.3.8 班牌及门禁对接
- 电子班牌显示预约信息、课程安排、使用状态
- 预约—审批—授权—开门全流程联动

---

### M04 实验项目管理

- 依据课程体系录入：项目名称、所属课程、实验类型（验证性/综合性/设计性/创新性）、学时、所需仪器/耗材、面向专业
- 批量复制至其他课程
- 按课程/专业/类型/学期统计，Excel 导入导出

---

### M05 故障及问题上报

- 在线提交：实验室、故障类型、描述、照片/视频
- 每间实验室专属二维码，扫码自动关联
- 管理员指派、进度更新、结果反馈，消息推送
- 按实验室/类型/状态/时间段统计分析

---

### M06 实验室数据填报管理

- 教育部基表标准化模板
- 在线填报、批量导入导出
- 集中归档、汇总统计、可视化展示

---

### M07 数据对接与集成

| 对接对象 | 同步内容 |
|----------|----------|
| 学校数据中心 | 人员、组织机构、场地、设备资产 |
| 安全考试/检查系统 | 考核成绩、检查记录 |
| 人脸数据中台 | 师生人脸数据，增量/变更同步 |
| 设备价值统计 | 按实验室/专业维度汇总资产价值 |

---

### M08 数据统计与分析

- 设备使用率（频次、时长、价值分层）
- 预约与人时数（人数×时长，按课程/项目/时间段）
- 实验项目统计（名称、数量、覆盖人次）

---

### M09 系统基础功能

| 子模块 | 要求 |
|--------|------|
| 用户管理 | 系统管理员、院系管理员、实验室管理员、教师、学生、临时人员，灵活 RBAC |
| 空间管理 | 楼栋 → 楼层 → 房间/空间，完整层级结构 |
| SSO | 统一身份认证平台单点登录 |
| 一卡通 | 刷卡签到、身份核验 |
| 移动端 | 微信小程序/钉钉，预约、故障上报 |
| 可视化大屏 | 运行态势、使用率、预约动态、安全数据、设备价值 |

---

### M10 智能体与 API 开放

- 标准化 MCP/REST API：实验室查询、设备台账、预约审批、故障上报、使用记录、统计数据
- 实时推送门禁核验、预约签到数据供违规监测
- 待办事项标准格式推送供 AI 助理分级提醒
- Text-to-SQL 结构化查询接口
- 制度/规程/FAQ 导入知识库，向量索引同步

---

### M11/M12 收费与支付 ★（重点需求）

- 银校直连、对公网银无缝对接
- 实验室经营性收入自动分账、资金归集、电子回单统一管理
- 实名制登记预约，校园卡/银校借记卡登录
- 实验室使用费、耗材费一键支付，入中国银行基本账

---

## 4. 非功能性需求

| 维度 | 要求 |
|------|------|
| 性能 | 支持校内并发预约高峰，列表查询 < 2s |
| 安全 | SSO 认证、RBAC 授权、操作审计、敏感数据加密 |
| 可用性 | 7×24 运行，关键服务高可用 |
| 可扩展 | 模块化设计，标准化 RESTful API |
| 合规 | 教育部数据申报格式、实名制收费合规 |
